# Selenium Web Automation Framework

A Java-based Selenium WebDriver automation framework for testing the public practice web application [SauceDemo](https://www.saucedemo.com/).

The framework uses **Page Object Model (POM)**, **TestNG**, **Maven**, explicit waits, data-driven testing, and failure screenshot capture to create maintainable and reusable UI automation tests.

---

## 🚀 Tech Stack

- **Java 17**
- **Selenium WebDriver 4**
- **TestNG**
- **Maven**
- **Page Object Model (POM)**
- **Google Chrome**
- **Git & GitHub**

## 🧪 Test Scenarios

The framework covers the following functional scenarios:

### Login
- Valid login
- Invalid login with:
  - Incorrect password
  - Unknown username
  - Locked-out user
- Empty username validation
- Empty password validation

### User & Product Operations
- Logout
- Verify products are displayed after login
- Add product to cart
- Remove product from cart

### Cart
- Navigate to cart
- Validate cart page
- Verify products added to the cart

---

## ⚙️ Automation Features

- **Page Object Model (POM)** for better maintainability and code reusability
- Separate **Page Objects** and **Test Classes**
- **Explicit waits** using `WebDriverWait` and `ExpectedConditions`
- Element identification using **ID and CSS selectors**
- **TestNG assertions** for validation
- **TestNG @DataProvider** for data-driven testing
- **Screenshot capture on test failure**
- **Headless browser execution** support
- Maven-based test execution
- Test execution using **testng.xml**
- Test execution reports generated by Maven Surefire
